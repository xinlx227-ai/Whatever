# Traditional tarot visual references

Superseded visual direction: the user rejected historical/realistic tarot and now wants existing stylized game card-back examples, without a tarot theme constraint. Retain this report only as research history; consult the planning handoff for current decisions.

Researched 2026-10-04 for the meal-decision app's card mode. The user requested traditional tarot styling instead of food-themed artwork. Research was delegated to a read-only researcher and integrated by the root. No deck has been selected or imported. Visual guidance below is design interpretation, not a requirement or historical claim.

## Original Rider-Waite Tarot Set

- [Official U.S. Games product page](https://www.usgamesinc.com/tarot-and-inspiration/all-products/original-rider-waite-tarot-set.html).
- The publisher describes the original palette and a pale-blue Tudor rose and lily card back. The site blocked direct retrieval with HTTP 403; no stable official image URL was extracted.
- Design interpretation: ivory margins, ink-like outlines, muted blue, red, ochre, and green; symmetrical floral backs. This is the classic illustrated direction, rather than a predominantly black-and-gold interface.

## Golden Tarot of Marseille

- [Official Lo Scarabeo product page](https://www.loscarabeo.com/en/collections/standard-tarot/products/golden-tarot-of-marseille).
- Modern edition restoring Claude Burdel's 1751 woodcut imagery with gold-foil printing.
- [Official face image](https://cdn.shopify.com/s/files/1/0512/8444/3315/products/4066_1200x1200.jpg?v=1617880933).
- [Official back image](https://cdn.shopify.com/s/files/1/0512/8444/3315/products/4069_1200x1200.jpg?v=1617880934).
- Visual observations: saturated primary colors, heavy outlines, pale margins and title bands; the back uses a red field with a gold star-like lattice.
- Design interpretation: a vivid, ornamental alternative to quiet blue-gray cards. Use its pattern rhythm as inspiration for a repeated card-back surface.

## Visconti Tarot

- [Official Lo Scarabeo product page](https://www.loscarabeo.com/en/collections/special-editions/products/i-tarocchi-dei-visconti).
- A modern restored gold-foil edition, not an original historical object.
- [Official Star face image](https://cdn.shopify.com/s/files/1/0512/8444/3315/products/1511_1200x1200.jpg?v=1623052385).
- [Official Justice face image](https://cdn.shopify.com/s/files/1/0512/8444/3315/products/2559_1200x1200.jpg?v=1623052385).
- [Official back image](https://cdn.shopify.com/s/files/1/0512/8444/3315/products/1513_1200x1200.jpg?v=1679990150).
- Visual observations: gold ornament and jewel-like face colors; a dark back with mirrored vase/floral ornament in bronze and teal.
- Design interpretation: the strongest reference here for a ceremonial courtly atmosphere. Dark backgrounds and restrained metallic lines could carry across the app while the revealed meal name stays clear.

## Decision boundary

These references compare illustration, borders, palette, and backs. The selected deck's exact artwork and reuse rights have not been adopted or cleared. The app still reveals meal choices; tarot styling does not add divination mechanics. Ask the user which visual direction fits before modifying the prototype.
