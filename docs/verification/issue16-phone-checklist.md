# Issue #16：手机普通规模手动检查

适用设备：OnePlus 9RT 5G（MT2110）。仅在电脑模拟器验证结束、验证安装包准备好后连接手机。

## 安装与数据隔离

- 安装独立应用“这一餐·验证”，包名 `com.xinlx227.whatever.verification`。
- 原应用“这一餐”的安装、数据库、图片和历史保持原样。
- 使用验证应用自带选项及少量临时选项。不要导入压力数据或在手机运行自动循环、性能测试、压力测试、冒烟测试。

## 手动操作

1. 分别体验转盘与抽卡：筛选、抽取、替换、确认，再到足迹检查完整名称与记录。
2. 抽卡左右滑动时不误选或翻牌；第一次激活选中，第二次激活翻开。离开视野再回来仍保留选中状态。
3. 做什么选十道菜，查看结果行首、中、尾，替换后保留其他菜；提前确认只保存已揭示的菜。
4. 横竖屏及系统最大字体＋最大显示大小下，完整名称、替换、确认、返回和筛选恢复入口可达，不被安全区遮挡。
5. 开启系统减少动画，检查转盘、翻牌、洗牌和收入结果的静态反馈，所有手动步骤仍保留。
6. 开启 TalkBack：筛选可操作；未揭示卡牌只读位置、总数及选中状态；移动焦点不选牌；两次无障碍激活依次选中和翻开；结果焦点、收入、重开、替换、确认及足迹可操作。TalkBack 的一次激活通常对应一次物理双击。
7. 如需检查照片，仅在验证应用中添加少量测试图片；退出重开后图片可读，图库原文件不变。
